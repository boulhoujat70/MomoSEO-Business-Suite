# MomoSEO & Business Suite

Application PHP dashboard sombre avec Tailwind CSS, MySQL et API Mistral AI.

## Installation

1. Importer `database.sql` dans MySQL.
2. Modifier `config.php` avec vos accès MySQL et votre clé API Mistral.
3. Lancer le projet sur XAMPP, WAMP, Laragon ou un serveur PHP.
4. Ouvrir `index.php`.

## Fichiers

- `index.php` : dashboard principal
- `config.php` : configuration
- `db.php` : connexion MySQL
- `mistral.php` : appel API Mistral
- `database.sql` : table historique
